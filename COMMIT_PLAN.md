# Meaningful Commit Plan

1. Create repository and add notebook imports.
2. Add abstract and problem formulation.
3. Add research questions and modelling hypotheses.
4. Implement synthetic sample generation.
5. Add data-quality checks and data dictionary.
6. Add descriptive statistics and group comparison.
7. Implement baseline and full logistic regression.
8. Add probit regression and mathematical explanation.
9. Add decision-tree benchmark.
10. Add ROC AUC, Brier score and log-loss validation.
11. Add calibration and threshold analysis.
12. Add VIF and overfitting diagnostics.
13. Add cross-validation sensitivity analysis.
14. Finalise results, limitations and conclusion.
15. Add references, self-assessment and README.

Each commit must contain a real change. Uploading all files together creates only one commit.
