# Mathematical Foundations, Comparison and Validation of Credit Risk Models

This repository contains a technical report implemented in Jupyter Notebook. It compares a baseline logistic regression, a multivariable logistic regression, a probit regression and a shallow decision tree on reproducible synthetic credit data.

## Main objectives
- analyse borrower characteristics with descriptive statistics;
- compare defaulted and non-defaulted observations;
- explain the mathematics of logistic and probit regression;
- validate discrimination, probability accuracy, calibration and overfitting;
- select a preferred model using several validation criteria.

## Main deliverable
`credit_default_model_comparison.ipynb`

## Reproducibility
Use Python 3.14 or later and install the packages from `requirements.txt`. Run the notebook with **Restart Kernel and Run All Cells**.

## Important limitation
All observations are synthetic. The project is educational and does not represent a production model or a real financial institution.
